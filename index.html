Project Overview

SkyPulse is a modern, responsive, high-performance Weather Forecast web application engineered for real-time atmospheric insights. It delivers real-time meteorological data, 24-hour hourly forecasts, 7-day extended outlooks, Air Quality Index (AQI) breakdowns, interactive Leaflet weather map overlays, and personal favourite locations.

Technology Stack
HTML5 CSS3 / Glassmorphism JavaScript (ES6+) Bootstrap 5.3 Chart.js 4 Leaflet.js OpenWeatherMap API
Key System Features
  • Glassmorphism responsive UI with dynamic weather animations.
  • Intelligent API fallback engine for 100% reliable offline/demo presentation.
  • Geolocation API auto-detection with custom city search.
  • Interactive Chart.js hourly & weekly temperature trends.
  • Interactive Leaflet map with Rain, Cloud, Temperature, and Wind layers.
  • Persistent Favourite Cities and Recent Search History via LocalStorage.
  • Dark/Light Theme and °C/°F Temperature Unit switcher.
